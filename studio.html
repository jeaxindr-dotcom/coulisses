Sur l'image

V Sélection : survole pour voir l'objet visé, clique, puis A pour demander une modif · D Dessin : plusieurs traits forment un seul dessin, ↵ pour l'ajouter · C Commentaire épinglé · P MP4 rendu ⇄ code actuel.

Mise en scène

M entrer ou sortir · clic sur un objet pour le choisir, puis tirer les poignées · W déplacer, E tourner, R échelle · ←→↑↓ Pg↑Pg↓ pousser l'objet (Maj ×5, Alt fin) · Échap désélectionner · Caméra libre pour regarder autour : glisser = tourner, clic droit = se déplacer, molette = avancer. Rien n'est écrit dans le projet : Ajouter à la file envoie le décalage à l'agent.

Lecture

Espace lecture · ←→ image par image, maintenir = défilement ×2 · Maj+←→ 1 seconde · Début Fin

Timeline (comme DaVinci Resolve)

molette = pistes vers le haut / le bas · Ctrl+molette = défiler dans le temps · Alt+molette = zoom horizontal · Maj+molette = hauteur des pistes · + - zoom · double-clic sur une réplique = note sur toute la réplique · glisser dans la bande Notes = nouvelle plage.

Notes

N note sur l'image · R début puis fin de plage · I O début / fin de la note choisie = image actuelle · L boucler la plage · Suppr effacer · Ctrl+V coller une image. Chaque nouvelle note entre dans Modifs, puis Envoyer à l'agent.

Rendu

Onglet Envois › Lancer le rendu : la demande part à ton agent, qui lance les cinq contrôles, le rendu et la finition. L'avancement s'affiche en haut de l'écran, et la nouvelle vidéo se charge toute seule. Comparer avant / après : glisser la barre sur l'image, B ou Espace tout avant / tout après, ←→ note précédente / suivante.
